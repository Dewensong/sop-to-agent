# GitHub Growth Playbook

## First-screen Promise

Lead with:

> Turn messy business SOPs into structured AI agent workflow specs.

This is more collectible than "marketing AI tool" and clearer than "workflow automation platform".

## Star Triggers

- A visible before/after example.
- 10+ realistic templates.
- CLI command that runs without an API key.
- Stable schemas and JSON outputs.
- Mermaid diagrams that can be pasted into docs.
- Adapter roadmap for n8n, Dify, and LangGraph.

## Launch Assets

- README first-screen screenshot or GIF.
- `examples/generated/marketing-campaign/report.md`.
- Blog post: `From SOP to Agent Workflow`.
- Short demo script:
  1. Paste marketing SOP.
  2. Show structured nodes.
  3. Show review gates.
  4. Export workflow JSON.
  5. Explain future adapter mapping.

## Interview Story

Use marketing as the first case, but keep the project generic:

> I built SOPilot to turn business interviews and SOPs into structured workflow specs. It identifies automation opportunities, marks human review gates, and exports artifacts that business, data, and IT teams can review together.
